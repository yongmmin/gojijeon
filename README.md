# 고지전

사내 LAN에서 4~8명이 브라우저로 붙어서 하는 2D 탑다운 **고지 쟁탈전**.

> 맵 한가운데에 고지가 하나 있다. **혼자 10초를 서 있으면 내 것이 되고,
> 그 자리에 포탑이 선다.** 손에 드는 건 딱 하나 — 곡괭이를 들면 땅은 파지만
> 싸우지 못하고, 칼을 들면 싸우지만 파지 못한다. 무기는 만들 수 없다.
> 벽을 뚫으면 나온다.

---

## 바로 켜기

```bash
npm install
npm run host
```

콘솔에 이런 상자가 뜹니다.

```
+---------------------------------------------------------+
| 고지전 - LAN 대전 서버                                   |
|                                                         |
| 팀원에게 이 주소를 보내세요:                             |
|    http://192.168.0.17:8080                             |
|                                                         |
| 내 브라우저:  http://localhost:8080                      |
+---------------------------------------------------------+
```

팀원은 **그 주소를 브라우저에 치기만** 하면 됩니다. 설치도, 빌드도 없습니다.

들어가면 **싱글플레이**와 **멀티플레이**로 갈립니다.

- **싱글** — 개인전/팀전을 고르고 컴퓨터 수를 정하면 바로 시작합니다. 서버에 AI가 들어 있어서 혼자서도 한 판이 성립합니다.
- **멀티** — 방을 만들면 **4자 코드**가 나옵니다. 그 코드(또는 함께 표시되는 링크)를 팀원에게 주면 들어옵니다.

> macOS에서 처음 켜면 "네트워크 연결 수신을 허용하시겠습니까?"가 뜹니다.
> **허용**을 눌러야 팀원이 들어올 수 있습니다. 실수로 거부했다면
> 시스템 설정 → 네트워크 → 방화벽 → 옵션에서 `node`를 허용으로 바꾸세요.

포트를 바꾸려면 `PORT=9000 npm run host`.

## 개발

```bash
npm run dev        # 게임 서버(8080) + Vite 개발 서버(5173) 동시 실행
npm run typecheck  # 전체 타입 검사
npm test           # 시뮬레이션 규칙 테스트
```

개발 중에는 `http://localhost:5173`을 엽니다. Vite가 `/ws`를 8080으로 프록시합니다.

## 규칙

### 손은 하나다

인벤토리가 없습니다. 들고 있는 것 하나가 전부입니다.

- 다른 걸 들려면 **지금 든 것을 바닥에 버려야** 합니다 (`Q`).
- 죽으면 들고 있던 무기가 **바닥에 떨어집니다.** 킬이 곧 전리품입니다.
- **곡괭이도 이 슬롯을 먹습니다.** 캐는 동안 당신은 무방비입니다.

### 무기는 만드는 게 아니라 파내는 것이다

제작대가 없습니다. 벽을 뚫으면 확률로 무기가 떨어집니다.

| 아이템 | 드랍 | 죽이는 데 | 흙벽 1칸 | 성격 |
|---|---|---|---|---|
| 곡괭이 | 기본 지급 (땅에서 안 나옴) | 13대 · 5.9초 | **1.4초** | 파는 건 제일 빠르고, 싸움은 제일 약하다 |
| 단검 | 흔함 | 7대 · **2.1초** | 2.7초 | 붙으면 이긴다. 이동속도 +15% |
| 망치 | 흔함 | 7대 · 5.3초 | 2.0초 | 건설·철거. 이게 없으면 기지가 없다 |
| 방패 | 흔함 | — | 2.7초 | 공격 불가. 정면 피해 80% 감소 |
| 창 | 드묾 | 4대 · 3.2초 | 2.7초 | 근접 최장 사거리, 긴 선딜 |
| 활 | 드묾 | 4대 · 3.2초 | 2.7초 | 통로 끝에서 일방적으로. 붙으면 무력 |
| 폭탄 | 희귀 | — | 2.7초 | 벽을 통째로 지운다. 쓰면 맨손 |

이 표는 `npm run digcheck`로 언제든 다시 뽑을 수 있습니다. 두 번 틀렸던 자리라
도구로 남겨 두었습니다 — 한 번은 단검이 곡괭이의 64% 속도로 땅을 파고 있었고,
한 번은 반대로 무기로는 한 칸에 5.4초가 걸려 "무기를 주우면 벌받는" 게임이었습니다.

흙벽은 8%, 광맥은 40% 확률입니다. 그래서 **파는 행위 하나에 광석과 무기라는
두 보상이 동시에 걸려 있고**, 좋은 게 나오면 곡괭이를 놓아야 하므로
보상이 곧 딜레마가 됩니다. 게임 안에서는 `C`로 확률표를 볼 수 있습니다.

바닥의 무기는 라운드가 끝날 때까지 사라지지 않습니다. 곡괭이를 여기 놓고
단검을 들고 갔다가 나중에 되찾는 플레이가 성립하도록 한 것입니다.

정확한 수치는 전부 [`balance.ts`](packages/shared/src/config/balance.ts)와
[`weapons.ts`](packages/shared/src/weapons.ts)에 있습니다. **밸런스는 거기서만 고칩니다.**

### 구급품

벽을 뚫으면 **14% 확률로 구급품**이 나옵니다. 가까이 가면 자동으로 주워지고
체력을 30 회복합니다. 단, **체력이 가득하면 줍지 않고 그 자리에 남습니다** —
멀쩡할 때 지나쳤다가 다치고 나서 되돌아오는 게 이 아이템의 요점이라
바닥에 2분간 남아 있습니다.

무기 추첨과 **따로** 굴립니다. 둘 중 하나만 나오게 하면 "무기가 나올 자리를
구급품이 먹었다"는 느낌이 들고, 다칠수록 파고 싶어지는 흐름도 끊깁니다.

### 자원은 건설에만 쓴다

- **광석** — 흙벽을 캐면 조금, 광맥을 캐면 많이. 벽·문·화톳불을 짓습니다.
- **코어 조각** — **적을 죽이거나** 맵 중앙 노드에서만 나옵니다. **포탑 전용.**

포탑(광석 120 + 조각 3)이 건설 트리의 꼭대기이고, 조각을 요구하는 유일한
건물입니다. 즉 **"포탑을 세우려면 사람을 죽이든 중앙을 먹든 하나는 해야 한다"**가
규칙 그 자체입니다. 구석에 틀어박히는 선택지를 경제로 막았습니다.

### 고지 — 이 게임의 이름

맵 한가운데에 상징물이 하나 있습니다.

- **자기 팀만** 그 둘레에 서 있으면 시계가 돌고, **10초**면 점령됩니다.
- 점령하면 옆 칸에 **포탑이 공짜로** 섭니다. 주인이 바뀌면 포탑도 갈립니다.
- 두 팀이 함께 서 있으면 **경합**이라 아무도 못 먹습니다. 밀어내야 합니다.
- 남이 점령해 둔 곳이어도 걸리는 시간은 **똑같이 10초**입니다. 규칙을
  "혼자 10초" 한 문장으로 설명할 수 있어야 하기 때문입니다.
- 자리를 뜨면 진행도가 천천히 되돌아갑니다. 막판 날치기가 안 됩니다.

### 한 판의 흐름

```
로비 → [ 준비 60초 → 전투 5분 → 라운드 종료 ] × N → 매치 종료
```

- **준비 페이즈**: 중앙이 봉쇄벽으로 막혀 있어 **고지를 점령할 수 없습니다.**
  사람은 때릴 수 있지만, 기지끼리는 길이 없어 실제로 마주칠 일이 거의 없습니다.
  전투 시작은 그 벽이 무너지는 순간이고, 동시에 전원이 중앙으로 달립니다.
  **싱글 플레이는 25초**입니다 — 혼자 하는 판에서 1분을 땅만 파는 건
  튜토리얼이 아니라 대기실입니다.
- **팀전**: 고지를 들고 있으면 **상대 코어가 초당 12씩 깎입니다.** 코어를 직접
  부수러 가도 됩니다. 먼저 0으로 만드는 쪽이 승리.
- **자유 대전**: 전원이 적. **고지를 누적 75초** 지키면 라운드 승.
- **죽어도 8초 뒤 부활합니다.** 두 모드 모두 그렇습니다 — 이기는 길이 상대를
  전멸시키는 것이 아니라 중앙을 밟고 서 있는 것이므로, 죽음은 퇴장이 아니라
  지연입니다. **부활하면 손에 든 것은 곡괭이로 초기화**되고, 죽을 때 들고 있던
  무기는 쓰러진 자리에 떨어져 있습니다.

3라운드를 먼저 가져가면 매치 승리입니다.

### 기지와 땅굴

기지는 암반 고리로 둘러싸여 있고, **틈이 둘**뿐입니다.

- **정문** — 중앙을 향한 넓은 입구. 여기서 고지까지 **구불구불한 진입로**가
  이미 뚫려 있습니다. 빠르지만, 상대도 그 길을 압니다.
- **뒷문** — 맵 바깥을 향한 좁은 틈. 흙벽 한복판에 묻혀 있어서,
  거기로 들어오려면 **긴 땅굴을 파야 합니다.**

진입로를 굳이 보장해 둔 이유가 있습니다. 예전에는 전부 파서 가야 했는데,
실측해 보니 **전투가 시작되고 중앙에 닿는 데만 1~2분**이 걸렸습니다
(`npm run sim`). 고지를 빨리 잡는 게 목적인 게임에서 그 시간은 통째로
죽은 시간입니다. 지금은 전투 시작 **2초** 만에 첫 교전이 벌어집니다.

곧은 길이 싫으면 흙을 파서 질러가면 됩니다. 그게 굴착이 전략인 이유입니다.

라운드마다 지형은 새로 생성됩니다. 지난 라운드의 땅굴은 물려받지 않습니다.

## 구조

```
packages/
├─ shared/     게임 규칙 전부. 서버와 클라가 같은 코드를 읽는다.
│  ├─ config/balance.ts     모든 수치의 단일 출처
│  ├─ tiles.ts              타일 레지스트리
│  ├─ weapons.ts            무기 레지스트리
│  ├─ buildings.ts          건축물 레지스트리
│  ├─ map/generator.ts      시드 기반 회전대칭 맵 생성
│  ├─ modes/                FFA / 팀전 — 승패와 부활 정책을 소유
│  ├─ sim/                  이동·전투·굴착·건설·고지 점령·라운드 진행
│  └─ protocol/             와이어 메시지 + RLE 압축
├─ server/     ws + 방 + 20Hz 틱 루프 + 정적 서빙 + LAN 주소 안내
│  └─ room/    manager.ts(방 목록·코드·세션) · room.ts(한 판) · ai.ts(컴퓨터)
└─ client/     Canvas 2D 렌더 + 입력 + HUD + 메뉴
```

### 지켜야 할 세 가지

1. **레지스트리가 진실이다.** 무기·건물·타일은 데이터로 정의합니다.
   새 무기를 넣는 일은 `WEAPONS`에 항목 하나를 더하는 것으로 끝나야 하고,
   전투·제작·렌더·UI 어디에도 `if (weapon === 'bow')` 같은 분기가 없어야 합니다.
2. **모드가 승패를 소유한다.** 시뮬레이션 코어에 `if (mode === 'ffa')`를 쓰지 않습니다.
   새 모드 추가가 기존 모드를 건드리지 않게 하는 유일한 방법입니다.
3. **서버가 유일한 권위다.** 클라는 "하고 싶다"만 보냅니다.
   상태는 오직 [`sim/`](packages/shared/src/sim/)에서만 바뀝니다.

### 방과 컴퓨터 플레이어

- 방은 **4자 코드**로 구분됩니다. 코드는 헷갈리는 글자(0/O, 1/I/L)를 뺀
  31자 알파벳에서 뽑습니다 — 옆자리 사람에게 **말로 불러 주는** 것이 주된
  전달 수단이라, 짧은 것보다 받아 적다 틀리지 않는 쪽이 중요합니다.
- **싱글 플레이도 그냥 방입니다.** 사람 하나에 봇 여럿인 방일 뿐이라,
  싱글/멀티를 가르는 분기가 서버에 거의 없습니다. 대신 싱글 방에는 남이
  못 들어오고, 마지막 사람이 나가면 즉시 정리됩니다.
- 방장(만든 사람)만 모드 변경·컴퓨터 수 조정·시작을 할 수 있습니다.
  방장이 나가면 다음 사람이 승계합니다.
- **AI에 길찾기가 없습니다.** 이 게임에서는 필요 없습니다 — 막히면 파면 됩니다.
  목표 방향으로 걷다가 벽에 닿으면 그대로 곡괭이질을 하는 것만으로 봇이 맵을
  가로지르고, 그 과정이 사람이 하는 것과 똑같은 땅굴을 남깁니다. A*를 얹었다면
  봇만 지형을 무시하고 다니는 이상한 게임이 됐을 것입니다.

### 네트워크

- 서버 권위, **20Hz 틱**. 클라는 60fps로 렌더하며 80ms 과거를 보간합니다.
- **클라 예측(prediction)은 구현하지 않았습니다.** LAN RTT가 1~3ms라
  이득이 없고 복잡도만 늘립니다. 인터넷으로 열 일이 생기면 그때 넣습니다
  (`sim/`이 순수 함수라 그대로 재사용됩니다).
- 지형은 접속 시 RLE로 한 번, 이후 바뀐 칸만 델타로.

## 테스트

```bash
npm test           # 규칙 (렌더·소켓 없음, 1초)
npm run test:e2e   # 진짜 WebSocket으로 붙는 서버 통합 테스트 (빌드 포함)
npm run test:all   # 둘 다
```

규칙 테스트에는 8인이 3000틱 동안 난동을 부려도 아무도 벽에 박히지 않는지
확인하는 내구 테스트가 들어 있습니다. 밸런스를 만진 뒤에는 이걸 먼저 돌리세요.

밸런스를 만진 뒤에는 **헤드리스 시뮬레이터**로 한 판을 통째로 돌려 보세요.
실시간 6분짜리 경기가 30밀리초 만에 끝나고, 무슨 일이 있었는지 숫자로 나옵니다.

```bash
npm run sim              # 팀전 4인 한 판
npm run sim ffa 6 3      # 개인전 6인, 3판
```

```
[1] 278초 만에 roundEnd (계산 32ms)
    고지: 첫 점령 74초 · 주인 바뀜 2회 · 최종 1팀
    현장: 첫 도착 64초 · 누가 서 있던 시간 132초 (그중 경합 3초) · 동시 최대 2팀
    굴착 120칸 · 무기 발굴 14개 · 사망 3회
```

"첫 도착"과 "경합 시간"을 따로 찍는 이유는, 고지가 안 먹히는 원인이
**아무도 안 왔기 때문인지** 아니면 **와서 서로 막았기 때문인지**가 완전히
다른 문제이고 고칠 곳도 다르기 때문입니다.

멀티플레이 흐름을 혼자 확인하려면, 방을 만든 뒤 그 코드로 가짜 손님을 붙입니다.

```bash
node tools/bot.mjs ABCD 3 8081
```

붙는 가짜 사람**이라 목적이 다릅니다 — 여러 명이 동시 접속했을 때의 네트워크와

## 배포

이 게임은 **방 상태를 메모리에 들고 20Hz로 도는 WebSocket 서버**입니다.
그래서 정적 호스팅이나 서버리스에는 올라가지 않습니다.

| | 가능? | 이유 |
|---|---|---|
| GitHub Pages · Vercel · Netlify | ❌ | 정적/서버리스. 상태 있는 소켓 서버를 못 띄웁니다 |
| Fly.io · Railway · Render | ✅ | 컨테이너 하나면 됩니다 |
| VPS (Lightsail · Vultr · Oracle) | ✅ | `docker run` 한 줄 |

### 리전이 전부입니다

지연이 조작 감각을 그대로 결정합니다. **플레이어와 가까운 리전**에 두세요.

| | RTT | 입력 → 화면 |
|---|---|---|
| 사내 LAN | 2ms | 69ms |
| 서울 | 8ms | 75ms |
| 도쿄 (Fly `nrt`) | 35ms | 102ms |
| 싱가포르 | 75ms | 142ms |
| 미국 서부 | 130ms | 197ms |

내 캐릭터는 보간을 건너뛰고 최신 위치로 수렴시킵니다
([`selfPose.ts`](packages/client/src/net/selfPose.ts)). 남의 캐릭터에만 80ms
보간이 걸립니다 — 남을 보는 부드러움과 내 손이 붙는 느낌은 다른 요구입니다.

### Docker

```bash
docker build -t gojijeon .
docker run -p 8080:8080 -e PUBLIC_URL="http://내주소:8080" gojijeon
```

`PUBLIC_URL`을 주면 시작 배너가 컨테이너 내부 IP 대신 그 주소를 찍습니다.

### Fly.io

```bash
flyctl auth login          # 직접 로그인해야 합니다
flyctl apps create gojijeon --org personal
flyctl deploy
```

[`fly.toml`](fly.toml)에 도쿄 리전(`nrt`)과 `/health` 헬스체크가 잡혀 있고,
**컨테이너를 재우지 않도록** 해두었습니다 — 방이 메모리에 있어서 자면
진행 중인 판이 사라집니다.

> 머신이 하나여야 합니다. 여러 대로 늘리면 접속이 분산되면서
> **같은 코드를 친 사람이 서로 다른 머신의 다른 방에 들어갑니다.**
> 여러 대가 필요해지면 방 상태를 Redis 같은 곳으로 빼야 합니다.

  "몰래 땅굴 파기"의 재미가 살려면 이게 필요하지만, 서버가 플레이어별로
  보이는 엔티티를 걸러야 해서 가장 무거운 조각입니다.
- 사운드, 미니맵 확대
- 채팅(프로토콜에는 있으나 UI 없음)
